# Contributing to Ghostwriter Swarm 🐝

We welcome contributions! Whether you're fixing a bug, adding a new feature, or improving the documentation, your help is appreciated.

## How to Contribute

1.  **Fork the Repository**: Create your own copy of the project on GitHub.
2.  **Create a Branch**: Use a descriptive name for your branch (e.g., `fix-auth-bug` or `add-new-agent`).
3.  **Make Your Changes**: Write clean, well-documented code.
4.  **Commit Your Changes**: Use clear, concise commit messages.
5.  **Push to Your Fork**: Upload your changes to your GitHub account.
6.  **Submit a Pull Request**: Explain your changes and why they should be merged.

## Code of Conduct

Please be respectful and helpful to others in the community. Let's build something great together!
